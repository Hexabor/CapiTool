# CapiTool 2.0

Hub de módulos para tiendas CeX: checklist, Xfer Reg, garantías, control de ajustes,
procurement y entrenamientos. Cada tienda ve solo los módulos que el administrador le activa.

- Login con cuenta Google (`@webuy.com`).
- Datos en Google Sheets (un archivo por tienda) dentro de Drive, a través de un Apps Script.
- Sin frameworks ni build: HTML, CSS y JS vanilla, publicado en GitHub Pages.

Publicación: https://hexabor.github.io/CapiTool/

Documentación de trabajo en `docs/` (empezar por `docs/ARRANQUE.md`). Sucesor de
[OmniTool](https://github.com/Hexabor/OmniTool) (v1).
